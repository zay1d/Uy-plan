# План дома (упрощённый, для расстановки мебели)

Чистые планы 1-го и 2-го этажей, снятые с чертежей КЖ (листы 9.1 и 9.2, «Схема расположения кирпичных стен»).

- `plan/plan-doma.pdf` — оба этажа, A3, масштаб 1:100 (1 см на бумаге = 1 м)
- `plan/etazh-1.png`, `plan/etazh-2.png` — картинки
- `plan/etazh-1.svg`, `plan/etazh-2.svg` — векторные (можно открыть в браузере или редакторе)

Размеры в сантиметрах, «в чистоте» (между стенами). Сетка 1×1 м.

Исходники: `source/`. Пересборка: `python3 tools/make_plan.py && node tools/render.js`.

## 3D-приложение (`app/`)

`app/index.html` — веб-приложение Uy Plan (один файл, открывается в браузере):
3D-модель дома с этажами друг над другом, вращение, режим «План», разнесение этажей,
срез стен, исходный чертёж как подложка, рулетка, схема вентиляции спален (рекуператоры,
шахты, трубы, решётки), загрузка своих 3D-моделей (.glb/.gltf/.obj), чертежей-картинок и проектов (.json).

Пересборка: `python3 tools/export_model.py && python3 tools/build_app.py`
(модель дома — `app/house.json`, исходник страницы — `app/index.src.html`).

## Вентиляция спален

Два рекуператора по 1000 м³/ч на кровле (по одному на каждую зеркальную половину дома),
приточно-вытяжная вентиляция только спален. Шахты — в кладовых и санузлах, решётки — в стенах спален.

- `plan/ventilyaciya.pdf` — 4 листа A3: 2-й этаж (шахты, трубы, решётки с привязками), кровля,
  1-й этаж (резерв), разрез + спецификация + кабели для электрика
- `plan/vent-*.png` — те же листы картинками
- расчёт и геометрия — `tools/vent.py`, чертежи — `tools/make_vent.py` + `tools/render_vent.js`
